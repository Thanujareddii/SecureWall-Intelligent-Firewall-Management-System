SecureWall - Intelligent Firewall Management System

How to run:
1. Open PowerShell inside this folder.
2. Run: pip install flask
3. Run: python app.py
4. Open: http://127.0.0.1:5000

Login flow:
- First page shows only Admin Access and User Access.
- Admin can add, edit, delete, enable/disable firewall rules and view logs.
- User can only check whether an IP address is allowed or blocked.
